## Bug Fix — Swagger UI 404

Prompt:
http://localhost:5000/api/system/status works but http://localhost:5000/swagger returns 404.

Root cause identified by AI:
No launchSettings.json existed, so dotnet run defaulted to the Production environment.
The IsDevelopment() guard in Program.cs silently blocked Swagger middleware from loading.

Changes made by AI:
1. Program.cs — removed IsDevelopment() guard; Swagger now always enabled (appropriate for MVP with no production deployment).
2. Properties/launchSettings.json — created with ASPNETCORE_ENVIRONMENT=Development and applicationUrl=http://localhost:5000.

Summary of AI response:
Identified root cause, applied two-file fix, verified HTTP 200 on /swagger/index.html.

Reviewer decision:
Confirmed working. Approved.
